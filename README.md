# Aveniq Digital Website

A responsive company landing page for **Aveniq Digital**, branded with the **AD** logo mark and navy, white, and light-blue colors.

## Files
- `index.html` — company landing page content
- `style.css` — responsive styling and brand colors
- `script.js` — mobile navigation and copyright year

## Publish with GitHub Pages
Upload these three files to the root of your repository, replacing the old versions. Keep the exact filenames shown above. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
